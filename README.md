# Lab07 - Exploratory Testing

**Оюутан:** Түвшинтөр  
**Оюутны код:** B190910820

## Лабораторийн зорилго

"Уншлагын жагсаалт" веб апп дээр exploratory testing
хийж, SBTM аргаар тестийн явцыг тэмдэглэх,
илэрсэн алдаануудыг баримтжуулах.

## Ашигласан хэрэгслүүд

- Ubuntu (WSL)
- Node.js
- Git
- Веб браузер

## Тестлэх програм

Багшийн өгсөн app.js файлыг ашиглана.

Програм ажиллуулах команд:

node app.js

Хаяг: http://localhost:3000

## Тестийн баримтжуулалт

- charter.md - Тестийн төлөвлөгөө
- session-report.md - 60 минутын тестийн тэмдэглэл
- bugs/ - Илэрсэн алдааны тайлан
- screenshots/ - Алдааны зураг
- evidence/ - API тестийн нотолгоо
