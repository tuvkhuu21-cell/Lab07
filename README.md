# Lab07 — Exploratory Testing (SBTM)

**Оюутан:** Түвшинтөр  
**Оюутны код:** B190910820  
**Огноо:** 2026-10-21

## Лабораторийн зорилго

"Уншлагын жагсаалт" веб аппликейшнд exploratory testing хийж, Session-Based Test Management (SBTM) аргаар тестийн явцыг баримтжуулах, илэрсэн алдааг нотолгоотой тайлагнах.

## Ашигласан орчин, хэрэгслүүд

- OS: Windows + Ubuntu (WSL)
- Node.js: v22.22.1
- Browser: Microsoft Edge 155.0.4283.62 (64-bit)
- Git
- GitHub
- Terminal, curl

## Програм ажиллуулах

Багшийн өгсөн `app.js` файлыг ашигласан.

Terminal дээр:

```bash
node app.js
```

Дараа нь браузераар:

`http://localhost:3000`

Тестийг black-box зарчмаар гүйцэтгэж, `app.js` файлын эх кодыг шалгаагүй.

## Тестийн баримтжуулалт

- `charter.md` — Тестийн зорилго, хамрах хүрээ болон tour-ууд
- `session-report.md` — SBTM session-ийн цагийн тэмдэглэл, ажиглалт
- `bugs/` — Алдааны дэлгэрэнгүй тайлангууд
- `screenshots/` — Браузерын алдааны зурган нотолгоо
- `evidence/` — API тестийн HTTP хариуны нотолгоо

## Тестийн үр дүн

- Тестийн хугацаа: ойролцоогоор 62 минут
- Ашигласан tour: Couch Potato Tour, Saboteur Tour
- Албан ёсоор баримтжуулсан алдаа: 7
- API-ийн алдааг `curl` ашиглан шалгасан
- Алдааны нотолгоог зураг болон текст файл хэлбэрээр хадгалсан

## Debrief

1. Энэ session-д "Уншлагын жагсаалт" аппликейшний ном нэмэх, хайх, устгах болон мэдээлэл харуулах үндсэн үйлдлүүдийг шалгасан.
2. Couch Potato Tour-ийн хүрээнд энгийн хэрэглэгчийн хийх үйлдлүүдийг туршсан.
3. Couch Potato Tour-ийн хүрээнд хоосон талбар, буруу он, давхардсан өгөгдлийг шалгаж, Saboteur Tour-ийн хүрээнд API руу буруу форматтай хүсэлт илгээсэн.
4. Номын гарчиг болон зохиогчийг хоосон үлдээсэн ч хадгалж болох алдаа илэрсэн.
5. Мөн зөвшөөрөгдөхгүй он болон давхардсан номын мэдээллийг систем хүлээн авч байгааг ажигласан.
6. API-д буруу JSON илгээхэд `200 OK` хариу буцсан нь анхаарал татсан.
7. Урт гарчиг хүснэгтийн харагдацыг эвдэж, хуучин хувилбарын холбоос серверийн алдаа харуулсан.
8. HTML тэмдэгттэй гарчиг оруулахад тэмдэгтүүд entity хэлбэрээр харагдсан.
9. Илэрсэн асуудлуудыг дахин үүсгэх алхам, severity болон нотолгоотойгоор баримтжуулсан.
10. Хугацааны хязгаарлалтын улмаас бүх боломжит оролт, олон хэрэглэгчийн зэрэгцээ ажиллагаа болон ачааллын тестийг бүрэн хамраагүй.
